## [0.1.0] - 2026-07-26

### Added

- `pi_history` Agent Tool with `list`, `search`, and `read` actions.
- `/history` interactive command for previewing, handing off, and resuming sessions.
- Cross-project lexical search over normalized Pi session records.
- Record pagination, cancellation, active-session exclusion, and exact-path confinement.
- UTF-8 byte, line, character, result-count, and scan-count output limits.
- English and Simplified Chinese documentation, CI, release automation, and npm package metadata.
